Queue Data Structure

A linear data structure that follows the First In First Out (FIFO) principle. The first element inserted is the first element removed.

What is a Queue?

A Queue is a linear data structure that follows the FIFO (First In First Out) principle.

Elements are inserted at the rear and removed from the front.

queue = [10, 20, 30, 40]
Index: 0 1 2 3 4
Value: 10 20 30 40 50

Advantages

  • Simple to implement
  • Fast insertion and deletion
  • Maintains FIFO order
  • Efficient scheduling
  • Useful in buffering

Disadvantages

  • No random access
  • Searching is slow
  • Array Queue may overflow
  • Less flexible than Linked List Queue

                // Dequeue the first element

A Queue is a linear data structure that follows the FIFO (First In, First Out) principle. Elements are added at the rear using enqueue and removed from the front using dequeue. Queues are commonly used in printer queues, CPU scheduling, task management, and Breadth-First Search (BFS).

Key Properties
  • FIFO ordering
  • Insertion at rear
  • Deletion at front
  • Fast enqueue operation
  • Fast dequeue operation
